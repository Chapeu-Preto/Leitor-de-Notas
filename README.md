# 📸 Gasto na Foto

Aplicação web para facilitar o controle de gastos a partir da leitura de comprovantes.

A proposta é simples: o usuário fotografa um comprovante e a aplicação utiliza inteligência artificial para identificar as informações do gasto, evitando a necessidade de inserir os dados manualmente.

## ✨ Funcionalidades

- 📷 Captura de comprovantes pela câmera
- 🤖 Leitura e interpretação do comprovante utilizando IA
- 💰 Registro dos valores gastos
- 📊 Exibição do total gasto
- 🧾 Contagem de comprovantes processados
- 📱 Interface simples e responsiva

## 🖥️ Interface

### Tela inicial

A tela inicial apresenta o total de gastos registrados e a quantidade de comprovantes processados.

![Tela inicial](imagens/Nota-Lida.jpg)

O usuário pode tocar na área **"Toque para fotografar o comprovante"** para iniciar a captura.

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```
2. Entre na pasta do projeto:
```bash
cd SEU-REPOSITORIO
```
3. Abra o arquivo index.html no navegador.
